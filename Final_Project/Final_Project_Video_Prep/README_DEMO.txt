ELEC5305 earlier demonstration materials — updated 5 November 2026

This folder preserves the earlier hard-gate demonstration and its preparation
materials. Open ../RUN_ORIGINAL_DEMO.m in MATLAB to run that example. The
release environment check locates Python and checks PySTOI 0.4.1 before
running video_demo. Final_Project_Study must remain adjacent to this folder.
Complete reproduction instructions are in ../README.txt and ../requirements.txt.

video_demo recomputes the predetermined sp02/street/5 dB example and matches
all four fresh scores to the frozen study. The lower figure panels are stored
48-condition averages. It does not retune parameters or rerun all cases.
play_demo_audio optionally plays same-gain 24-bit audio files. No listening
quality ratings were collected. Outputs are written only in demo_generated.

English_Read_Aloud.txt, SCRIPT_CONTENT.json and Teleprompter.html are retained
earlier preparation materials, including the earlier conclusion. The current
eight-chapter spoken transcript is ../video/Final_Video_Transcript.txt. To
display earlier controlled-study figures, use show_controlled_results from
the package root; this displays stored results rather than recomputing them.
The main report consistently uses standard PySTOI; native MATLAB scores
remain in the historical archive only.

The completed 6 min 31 sec video is at ../video/index.html, with burned-in
English captions, MP4, SRT, eight chapter markers and the current transcript.
Its first six chapters preserve the actual earlier MATLAB run and the stored
parameter-study and controlled-diagnostic results. New recorded narration
presents soft-SPP results through figures and result cards. Open ../START_HERE.m
to run the separate new sp03/street/+6 dB-rise soft-SPP demonstration.
The Chinese guide and Tutor问答_中文.txt explain the earlier concepts.

TSNR source attribution and the original licence remain in ../Final_Project_Study
and ../Project_Feedback_Two_NOIZEUS. The shared enhancement algorithm derives
from LIU Ming / Pascal Scalart's implementation. Soft-SPP sources and licences
are retained separately in ../spp_recovery.
