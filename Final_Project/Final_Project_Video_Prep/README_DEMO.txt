ELEC5305 final demonstration — 21 October 2026

Open ../START_HERE.m in MATLAB and press Run. The release environment check
locates the configured Python and checks PySTOI 0.4.1 before running video_demo.
Final_Project_Study must remain adjacent to this folder. Required software and
complete reproduction instructions are in ../README.txt and ../requirements.txt.

video_demo recomputes the predetermined sp02/street/5 dB example and matches
all four fresh scores to the frozen study. The lower figure panels are stored
48-condition averages. The demo does not retune parameters or rerun all cases.
play_demo_audio optionally plays same-gain 24-bit audio files. No listening
quality ratings were collected. Outputs are written only in demo_generated.

English_Read_Aloud.txt, SCRIPT_CONTENT.json and Teleprompter.html now contain
the actual final narration, including the stored controlled noise-change results. To display those
figures, use show_controlled_results from the package root. This is a display
command, not a fresh controlled-study run. The main report consistently uses
standard PySTOI; native MATLAB scores remain in the historical archive only.

The completed 5 min 24 sec video is in ../video/index.html, with burned-in
English captions, a downloadable MP4, SRT captions and the spoken transcript.
Its MATLAB screen capture shows an actual run. The main study means and the
controlled-study results are explicitly identified as previously stored results.
The Chinese guide and Tutor问答_中文.txt explain the concepts for discussion.

TSNR source attribution and original licence remain in ../Final_Project_Study
and ../Project_Feedback_Two_NOIZEUS. The demonstration's shared enhancement
algorithm is derived from LIU Ming / Pascal Scalart's original implementation.
